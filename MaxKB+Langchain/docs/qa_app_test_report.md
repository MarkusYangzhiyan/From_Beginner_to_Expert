# Day 053 星云商城客服助手测试报告

## 1. 测试目标

验证 MaxKB 问答应用是否可以基于“星云商城客服知识库”正确回答售后、退货退款、物流配送、发票会员等电商客服问题，并在知识库没有相关内容时执行拒答策略。

## 2. 测试配置

- 问答应用名称：星云商城客服助手
- 大语言模型：deepseek-v4-flash
- 向量模型：bge-m3 或 maxkb-embedding
- 关联知识库：星云商城客服知识库
- 测试文档：
  - `ecommerce_after_sales_policy.md`
  - `ecommerce_return_refund_policy.md`
  - `ecommerce_shipping_policy.md`
  - `ecommerce_invoice_member_policy.md`

## 3. 推荐测试参数

- Top-K：5
- 相似度阈值：0.30-0.40
- 回答语言：中文
- 拒答策略：知识库没有依据时，应回答“根据当前知识库资料，暂时无法确认该问题，请联系人工客服进一步处理。”

## 7. 测试结论

- 知识库内问题是否可以稳定回答：可以。28 条知识库内问题中，27 条完整正确，1 条部分正确，整体回答稳定。

- Top-K 和相似度阈值是否需要调整：当前参数基本可用。建议后续针对优惠券、例外规则、复杂条件类问题继续微调 Top-K 和相似度阈值。
- Prompt 是否需要继续优化：需要轻微优化。建议加入“涉及优惠券、退款、时效、责任归属、例外情况时，必须列出知识库中的具体条件，不要只建议联系人工客服”。
- 是否达到 Day 053 验收标准：达到。已创建问答应用，完成知识库绑定、Prompt 调整、Top-K/阈值测试，并完成 30 条问答测试记录。
