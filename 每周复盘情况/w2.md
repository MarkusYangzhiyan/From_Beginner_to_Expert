# 第二周复盘

## 本周完成

- 将单脚本重构为 `product_app` Python 包，按职责拆分数据模型、数据读写、业务逻辑、用户交互和程序入口。
- 使用 `dataclass` 创建 `Product` 数据模型，实现字典与对象之间的双向转换。
- 为公开函数补充类型提示，并使用 `Enum` 管理固定菜单选项。
- 使用 `logging` 记录数据加载失败、查询无结果和商品添加等操作，同时输出到终端和日志文件。
- 使用 Ruff 检查代码风格和明显问题。
- 使用 Pytest 和 Arrange-Act-Assert 编写查询、排序、异常、添加、保存和命令行参数测试，共 12 个测试通过。
- 使用 `argparse` 增加 `search`、`add` 子命令，并校验必填文本和价格参数。
- 完成 Git 创建本地分支、差异查看、合并、远程分支、Pull Request、Review 和 `git revert` 练习。
- 完善 README 的环境、安装、运行、测试和代码检查说明。

## 本周学到

- 模块和包用于组织代码；`__init__.py` 让目录成为可导入的 Python 包。
- `Enum` 适合管理数量固定且有名称的常量。
- 日志配置应由程序入口main统一完成，各业务模块只通过 `logging.getLogger(__name__)` 获取日志器。
- Pytest 的测试函数需要以 `test_` 开头；`tmp_path` 可以隔离文件测试，避免修改真实数据。
- `argparse` 的 `required` 控制参数是否必须提供，`type` 负责类型转换和自定义校验。


## 遇到的问题与解决方法

- Push 被远程新提交拒绝：使用 `git fetch` 查看差异，再通过 `git pull --rebase` 整合远程 PR 提交。
